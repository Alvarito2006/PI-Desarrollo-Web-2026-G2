# PI - Desarrollo Web 2026 - Grupo 2

Aplicación web de prueba para Prácticas Iniciales, segundo semestre 2026. Permite registrar estudiantes, iniciar sesión, recuperar contraseña, publicar opiniones sobre cursos o catedráticos, comentar publicaciones, buscar perfiles y administrar cursos aprobados y créditos.

## Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Base de datos: MySQL
- Autenticación: JWT + bcryptjs
